| 項目 | 可否 |

| 商用利用 | OK |
| 利用報告 | 不要 |

| 素材を加工して作品に利用 | OK |

| **素材としての再配布・販売** | **加工の有無に関わらず禁止** |

### 本作での扱い（重要）

- 背景はゲームに組み込んで使用している＝「作品への利用」であり、許可された範囲
- **やってはいけないこと**：
  - `public/assets/bg/` の画像を素材として配布・販売する
  - 素材ファイルだけをまとめて公開リポジトリに置き、ダウンロード可能な形で提供する
  - 加工したものを別の素材集・テンプレートとして配布する
- 本作は**限定公開**（noindex／URLを知っている人のみ）のため、素材が不特定多数に素材として拡散する形にはならない
- 原本の JPEG は `bg/*.jpg` として残してあるが、これも上記の理由から**外部に配布しないこと**

## BGM（4曲）

**出典：甘茶の音楽工房** — https://amachamusic.chagasi.com/

| ファイル | 曲名 | 分類 | 使用箇所 |
|---|---|---|---|
| `bgm/bgm_daily.*` | 夏色のキャンパス | おしゃれ／ポップ（ピアノ・パーカッション） | Scene1〜5、②進展なしエンド |
| `bgm/bgm_evening.*` | 夕暮れのキャンパス | おしゃれ／ポップ（ピアノ・パーカッション） | Scene6、Scene8 |
| `bgm/bgm_honne.*` | 現実の隙間 | 暗い／ピアノ | Scene7（🎤④の直前から） |
| `bgm/bgm_ending.*` | 月明かりの灯台 | しみじみ／ピアノ | ③拒否エンド、④成功エンド |

`bgm_daily` と `bgm_evening` は**同じ作者の昼／夕方の対になる曲**。背景（商店街の昼／夕方）の時間差分と揃えてあり、Scene6で背景と同時に切り替わる。
**①バレエンドは曲を使わず停止（無音）。**

### 確認した利用条件（2026-08-23 時点・利用規約ページ記載）

| 項目 | 可否 |
|---|---|
| 商用利用 | OK（「商用利用、個人利用問わず利用できます」） |
| **ゲーム・ウェブでの使用** | **OK**（「ウェブ、映像、ゲーム、ラジオなど、何かのBGMとしてお使い下さい」と用途が明記） |
| 加工（テンポ・キー変更、フェード等） | OK |
| クレジット表記 | 任意（リンクorクレジットが推奨されている → 本作では表記する） |
| 音楽だけの販売・2次配布 | **禁止** |
| **直リンク** | **禁止**（素材はダウンロードして自分のサーバーに置くこと） |

### 本作での扱い（重要）

- MP3を**ダウンロードして自分のサーバーに配置**している。甘茶のサーバーへ直リンクはしていない（規約が明示的に禁じている）
- 配信用に AAC(.m4a) へ変換している。形式変換は許可された加工の範囲
- **やってはいけないこと**：`public/assets/bgm/` のファイルを楽曲として配布・販売する／素材集に含める

### DOVA-SYNDROME を使わなかった理由

当初 DOVA-SYNDROME（https://dova-s.jp/）を検討したが、音源利用ライセンスに次の条項がある。

> コンバート等を行わず、エンドユーザーが容易に音源ファイルに音声ファイルとしてアクセス、複製が可能な状態での利用（禁止事項）

Webゲームは素材をURLで配信する以上、この条項に触れないと言い切りにくい。
甘茶の音楽工房は規約で**「ウェブ」「ゲーム」を用途として明記**しており、同種の制限もないため、こちらを採用した。
DOVAを使う場合は、上記条項について運営に確認を取ることを勧める（同サイトには問い合わせ窓口がある）。

## 効果音（4点）

**出典：効果音ラボ** — https://soundeffect-lab.info/

| ファイル | 元素材 | 長さ | 使用箇所 |
|---|---|---|---|
| `se/se_select.*` | ボタン・システム音「決定ボタンを押す29」 | 0.20秒 | 本編で選択肢を決定したとき |
| `se/se_confirm.*` | 同「決定ボタンを押す3」 | 0.85秒 | 録音を確定して次の1本へ進むとき |
| `se/se_rec_start.*` | 同「beep1」 | 0.32秒 | **録音開始の合図** |
| `se/se_rec_stop.*` | 同「beep3」 | 0.39秒 | 録音停止の合図 |

`se_rec_start` は1458Hz、`se_rec_stop` は1032Hz。**開始より低い音で終わりを示す**ようにペアで選んである。

### 確認した利用条件（2026-08-23 時点・利用規約ページ記載）

| 項目 | 可否 |
|---|---|
| 商用利用 | OK（個人・法人・公的機関問わず無料） |
| **アプリへの操作音としての組み込み** | **OK**（規約に明記） |
| 加工 | OK（ただし**改変したものの再配布は禁止**） |
| クレジット表記 | 不要 |
| 直リンク | **禁止**（ダウンロードして自分のサーバーに置くこと） |
| 音が主役のコンテンツ（効果音を鳴らすアプリ等） | **禁止**（再配布と同じ扱い） |

本作は効果音を**操作音として組み込んでいる**だけで、音を聴かせること自体が目的ではないため、許可された用途に収まる。
MP3をダウンロードして自分のサーバーに置いており、直リンクはしていない。

### なぜ効果音だけWAVなのか

配信用は WAV（モノラル22.05kHz）にしている。0.2秒程度のUI音にMP3/AACの**エンコード前詰め（数十msの無音）**が乗ると、押した瞬間の反応が鈍って感じられるため。
短いので**4点あわせて77KB**にしかならず、サイズ上の不利はない。

## 配信ファイルについて

`optimize_assets.py` が原本から配信用ファイルを生成し、アプリはそちらを読む。

| 種別 | 原本 | 配信用 |
|---|---|---|
| 立ち絵・背景 | PNG / JPEG（13.0MB） | **WebP（1.40MB）** |
| BGM | MP3 128kbps（8.5MB） | **AAC .m4a 96kbps（6.47MB）** |
| 合計 | 21.5MB | **7.87MB**（設計書8.6節の上限10MBに対して79%） |

原本はリポジトリ内に残すが、**原本・配信用のいずれも素材として外部に配布しないこと**（両サイトとも再配布を禁じている）。
