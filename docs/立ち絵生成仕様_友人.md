# 立ち絵生成仕様｜友人（彼氏）

Stability Matrix で生成するための仕様。**彼女の立ち絵と並べて破綻しないこと**が最優先。

操作手順（起動から納品まで）とプロンプト全文は [立ち絵生成手順_友人.md](立ち絵生成手順_友人.md)。
このファイルには「何を作るか」だけを書く。以下は彼女の画像から実測・観察した値。

---

## 1. 必要な差分

| ファイル名 | 用途 | 感情 | 必要度 |
|---|---|---|---|
| `normal.png` | Scene1〜8の通常時、🎤⑤、②エンド | ゆるい薄笑い、締まりのない普通の顔。口は閉じる | **必須** |

## 2. 彼女の立ち絵の実測値（これに合わせる）

| 項目 | 値 |
|---|---|
| 画像サイズ | **768 × 1152 px**（縦2:3） |
| 形式 | **PNG / RGBA・背景は完全透過**（alpha=0） |
| 頭頂の位置 | 上端から **35px（約3%）** |
| 人物の高さ | 1117px（頭頂〜画像下辺） |
| 下端 | **画像の下辺で切れている**（膝上あたりでフレームアウト） |
| 人物の横幅 | 約471px |
| 人物の中心x | 約416px（画像中心384pxよりわずかに右） |
| 顔の位置 | 目の高さが上端から **y≈200〜235px** |

### 画風の特徴（観察）

- フラットなセルシェード。影は**グラデーションではなく硬い面**で落ちる
- 線画は太めで均一、色は彩度低め（グレー・黒・くすんだ紫）
- 正面〜やや斜め向き、立ち姿、**腕は自然に下ろして体側に沿わせる**
- 表情差分は**顔以外まったく同じ**（服・ポーズ・影の落ち方が1pxもズレていない）

> 最後の点が重要です。彼女の7枚は明らかに**1枚の元画像から顔だけを描き変えて**作られています。
> 友人も同じやり方（後述の「差分の作り方」）で作ってください。

## 3. キャラクター設定

台本上の役どころ：**30歳・男性・プレイヤーの大学からの旧友。屈託がなく明るいが、少し無神経。彼女がいる。**

見た目の方針：**金髪でチャラく、少し不出来に見える男。**

| 項目 | 指定 | 理由 |
|---|---|---|
| 髪 | **明るい金髪**（ブリーチ）、短髪、無造作にかき上げた前髪、サイドは刈り上げ | 彼女の銀髪と明度で近づきすぎないよう、黄みの強い金にする |
| 目 | **明るいブラウン、垂れ目、眉は細い** | 垂れ目＋細眉が「締まりのない・不出来そう」を作る要 |
| 服 | **えんじの柄シャツ（襟を開けて白インナー）＋黒のスリムパンツ** | 彼女がグレー×黒なので、彩度で分離する |
| 小物 | **ゴールドのネックレス、腕時計**（顔から離れた位置のみ） | チャラさを足す。顔マスクの外なので表情差分に影響しない |
| 体型 | 細身でひょろっとしている | 頼りなさを出す |
| 付けないもの | 眼鏡・帽子・ネクタイ・ジャケット | 差分作成の邪魔になる／休日の場面に合わない |

**スーツにしないこと。** 土曜の昼に街を歩いている休日の場面。

## 6. 差分の作り方（顔以外を一致させる）

seedを固定してタグだけ変えても、服のシワや影は微妙にズレます。彼女の7枚のように**完全に一致**させるには：

1. まず `normal` を1枚だけ気に入るまで生成する（これが元画像）
2. その画像を **inpaint** に送る
3. **顔まわりだけをマスク**（眉・目・口。輪郭や髪の外側は含めない）
4. プロンプトの表情タグだけを差し替えて inpaint。彼女と同じ `Denoising strength 0.75`・`Only masked`・`Only masked padding 64`・`Mask blur 4`・`CFG 5`
5. 3〜4を表情の数だけ繰り返す

この手順なら、服・ポーズ・影・背景がすべて `normal` と同一のまま顔だけが変わります。

## 7. 後処理

`chara_cutout.py` が透過・トリミング・位置合わせをまとめて行います（rembg等のインストールは不要）。

```
python chara_cutout.py <作業用フォルダ>/*.png -o public/assets/chara/friend
```

- 外周から繋がった白だけを抜くので、**白いインナー・腕時計の文字盤・シャツのボタンは残ります**
- 逆に、腕と胴の間のように外周とつながっていない背景は自動では抜けません。
  `--list-islands` で一覧を出し、背景のものを `--hole x,y` で指定します（手順書 STEP4）
- 頭頂 35px・中心x 416px・彼女の1.05倍に自動で揃えます（倍率は `--scale`、位置合わせ不要なら `--no-align`）
- 出力は 768 × 1152 の PNG（RGBA）

### 身長差について

30歳男女なので、**友人は彼女より少し背が高く見えるべき**です。
同じ枠に同じ大きさで描くと同じ身長に見えてしまうため、**人物の高さを彼女の約1.05倍**にします。

この倍率は `chara_cutout.py` が既定で掛けています（`--scale 1.05`）。手作業での調整は不要です。

## 8. 納品先

```
public/assets/chara/friend/normal.png
public/assets/chara/friend/suspicious.png
public/assets/chara/friend/smile.png      ← 任意
public/assets/chara/friend/cold.png       ← 任意
```

PNGを置いたあと `python optimize_assets.py` を実行すると、配信用の `.webp` が生成されます。
その後 `sw.js` の `CRITICAL` 一覧と `CACHE_VERSION` の更新が必要です（こちらで対応可）。

**ファイルを置くまでの間**、ゲーム内では友人の立ち絵の代わりに差分名を表示するプレースホルダが自動で出ます。
`normal.png` だけ置いた状態でも動作するので、1枚できた時点で画面で確認できます。
