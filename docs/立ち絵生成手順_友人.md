# 立ち絵生成手順｜友人（彼氏）

Stability Matrix で友人の立ち絵を作るための、あなた向けの作業手順書。
何を作るか（差分の種類・キャラ設定・納品先）は [立ち絵生成仕様_友人.md](立ち絵生成仕様_友人.md) を参照。
ここには **どう操作するか** だけを書く。

---

## 0. 前提

使うのは **Stable Diffusion WebUI reForge**。彼女の立ち絵と同じ設定で作る。

> forge-neo は起動しない。このPCのGPUはAMD（Radeon RX 6600 XT）だが、forge-neo にはCUDA版の
> torch が入っているため。ドライバ更新では直らないので、reForge を使うこと。

### 生成設定（彼女と同一）

| 項目 | 値 |
|---|---|
| チェックポイント | **holyMixIllustriousxl_v1**（hash `71f6653377`） |
| LoRA / VAE | **なし** |
| サンプラー | **Euler a** / Schedule type: Automatic |
| Steps | **20** |
| CFG | **7**（txt2img） / **5**（表情差分のinpaint） |
| Clip skip | **2** |
| 解像度 | **768 × 1152** |
| Hires.fix / ADetailer | **なし** |

### 所要時間の目安（RX 6600 XT / 8GB）

| 処理 | 時間 |
|---|---|
| reForge の起動 | 約27秒 |
| txt2img（768×1152 / 20 steps） | 約80秒/枚 |
| inpaint（Only masked / 768×768） | 約5分/枚 |

VRAM 8GB で SDXL はそのまま乗る（`NORMAL_VRAM`）。追加の起動引数は不要。

**reForge を同時に2つ起動しないこと。** VRAMを取り合って1枚あたり3倍近く遅くなる。

### 彼女のデータ

| | 場所 |
|---|---|
| 元画像 | `Data\Images\Text2Img\2026-08-15\00002-3402663755.png` |
| 表情差分 | `Data\Images\Img2Img\2026-08-15\` に23枚（採用7枚＋没） |

彼女の元プロンプト全文は、上のPNGを reForge の **PNG Info** タブに放り込めば出る。
UIもコミットも当時のままなので、**彼女のseedを入れれば彼女の絵をそのまま再現できる**。

友人のプロンプトは、彼女のプロンプトと行の並びと書式をそろえてある（STEP2）。
画風はチェックポイントだけでなく先頭の品質タグ列でも決まるので、`masterpiece, best quality, ...` の行を省かないこと。

## STEP 1. reForge を起動して設定を合わせる

1. Stability Matrix を起動 → 左メニュー **Packages** → **Stable Diffusion WebUI reForge** → **Launch**
   - 起動引数（Launch Options）は**空のままでよい**。8GBでSDXLは `NORMAL_VRAM` で通る
2. ブラウザでUIが開いたら、画面上部で以下を設定する
   - **Checkpoint**: `sd\holyMixIllustriousxl_v1.safetensors`
   - **VAE / Text Encoder**: 空（何も選ばない）
   - **Clip skip**: **2** ← 初期値は1。**必ず2に変える**（reForgeは上部バーにスライダがある）
3. **txt2img** タブを開き、生成設定を合わせる
   - Sampling method: `Euler a` / Schedule type: `Automatic`
   - Sampling steps: `20`
   - Width `768` / Height `1152`
   - CFG Scale: `7`
   - Hires.fix: **オフ**、ADetailer: **オフ**
   - Batch count: `4`（1枚80秒なので、4枚で約5分）

> **うまくいかないときだけ**追加する起動引数（Stability Matrix の reForge → Launch Options）
> | 症状 | 引数 |
> |---|---|
> | VRAM不足（OOM）で落ちる | `--medvram-sdxl` |
> | 生成結果が真っ黒／ノイズだけになる | `--no-half-vae` |
> | 極端に遅い・途中で固まる | `--use-split-cross-attention` |

## STEP 2. normal を1枚決める（txt2img）

これから作る4枚は、**すべてこの1枚から派生させる**。ここで妥協しないこと。

### ポジティブプロンプト

```
masterpiece, best quality, amazing quality, very aesthetic, absurdres, newest,
1boy, solo, male focus, cowboy shot, standing, facing viewer, looking at viewer, arms at sides,
mature male, 30 years old, slim, lanky, casual clothes,
(blonde hair:1.3), bleached hair, short hair, messy hair, swept back bangs, undercut,
(light brown eyes:1.1), droopy eyes, thin eyebrows,
(dark red patterned shirt:1.2), open collar, unbuttoned, white undershirt, gold necklace, black slim pants, wristwatch,
(light smirk:1.2), relaxed expression, half-closed eyes, closed mouth, carefree,
simple background, white background, even lighting, anime style, clean lineart, cel shading
```

チャラさと軽薄さは、この3行が担っている。強度を変えたいときはここを触る。

| 行 | 役割 | 強めたいとき |
|---|---|---|
| `(blonde hair:1.3), bleached hair, ... undercut` | 明るい金髪・遊んでいる頭 | `bleached hair` を `(bleached blonde hair:1.2)` に |
| `droopy eyes, thin eyebrows` | 締まりのない顔立ち（不出来そうに見える要） | `thin eyebrows` を `(thin eyebrows:1.2)` に |
| `gold necklace, wristwatch, unbuttoned` | アクセ・着崩し | `earrings` を足す（耳はマスク外なので差分に影響しない） |

### ネガティブプロンプト

```
lowres, worst quality, low quality, bad anatomy, bad hands, missing fingers, extra digits, fewer digits, extra arms,
jpeg artifacts, signature, watermark, username, artist name, text, logo,
blurry, depth of field, multiple views, multiple boys, 2boys,
1girl, female, breasts, nsfw, nude,
black hair, brown hair, silver hair, white hair, pink hair, blue hair, purple hair, green hair, red hair,
long hair, ponytail, ahoge, hair bun, bald,
old man, elderly, wrinkles, beard, mustache, stubble, muscular, obese,
suit, business suit, necktie, formal, hat, glasses, sunglasses, jacket, coat,
serious expression, stern, angry, glaring, scowl, gloomy, shadow over face,
full body, feet, shoes,
cropped, head out of frame, from behind
```

- 髪色を全部ネガティブに入れているのは、金髪を確実に出すため
- `serious expression, stern` は、真面目そうな顔に寄るのを防ぐため
- `suit, necktie, formal` は休日の場面のため。`full body, feet, shoes` は彼女と同じ膝上フレームにするため

### 手順

1. Seed は `-1`（ランダム）のまま **Generate** を何度か押し、候補を貯める（1枚あたり約80秒）
2. 選ぶ基準（この5点を満たすものだけ通す）
   - **膝上でフレームアウト**していて、足が画面に入っていない（彼女と同じ構図）
   - **腕が体側に自然に下りている**（腕組み・ポケットに手・手を上げているものは落とす）
   - **手が破綻していない**（指が5本、融合していない）
   - **背景が真っ白**で、床の影や壁の線が入っていない
   - **影が黒ベタの硬い塊になっていない**。このプロンプトは80年代アニメ調の濃い影が出ることがあり、
     彼女（影が柔らかい）と並べると浮く。影が軽いものを選ぶこと
3. 決まったら、その画像の下に出ている **Seed をメモ**して、Seed欄に固定で入れておく
   （あとで作り直したくなったときに同じ絵に戻れる）
4. 画像を **PNG形式のまま保存**（生成物は自動で `Data\Images\Text2Img\日付\` に入る）

> 白背景のまま作ること。透過はSTEP4でこちらのスクリプトが行う。
> UI側で透過生成を試みると、彼女の7枚と輪郭の処理が変わってしまう。

## STEP 3. 表情差分を作る（inpaint）

彼女の7枚は、seedを変えて撮り直したのではなく、**normalの顔だけをinpaintで描き変えて**作られている。
だから服のシワも影も1pxもズレていない。友人も同じ手順を踏む。

1. STEP2で決めた画像の下の **Send to inpaint** を押す（img2imgタブのInpaintに転送される）
2. 画像の上を**マウスでなぞって顔だけを白く塗る**
   - 塗る範囲：**眉・目・鼻・口**。頬の内側まで。
   - 塗らない範囲：**輪郭線の外・髪・耳・首**。ここを含めると差分間で頭の形が変わる。
3. 右側の設定を合わせる（彼女のときと同じ値）

   | 項目 | 値 |
   |---|---|
   | Mask blur | `4` |
   | Mask mode | `Inpaint masked` |
   | Masked content | `original` |
   | Inpaint area | **`Only masked`** |
   | Only masked padding, pixels | `64` |
   | Resize to | Width `768` / Height `768` |
   | Sampling method / Steps | `Euler a` / `20` |
   | **CFG Scale** | **`5`**（txt2imgの7から下げる） |
   | **Denoising strength** | **`0.75`** |
   | Seed | `-1` のままでよい |

   > Seedを固定しなくてよいのは `Only masked` のおかげ。マスクの外の画素は一切再生成されないので、
   > 服・ポーズ・影は必ずnormalと同一になる。

4. プロンプトの**表情の行だけ**を差し替えて Generate する。他の行は1文字も変えないこと。

   | 出力ファイル | 差し替える行 |
   |---|---|
   | `normal.png` | `(light smirk:1.2), relaxed expression, half-closed eyes, closed mouth, carefree,` ← STEP2の絵をそのまま使う |
   | `suspicious.png` | `frown, narrowed eyes, suspicious, raised eyebrow, closed mouth,` |
   | `smile.png` | `wide grin, open mouth, laughing, cheerful, happy,` |
   | `cold.png` | `expressionless, jitome, half-closed eyes, flat mouth, cold stare,` |

   `suspicious` と `cold` のときは、ネガティブから `serious expression, stern` を外す
   （訝しむ顔・冷えた顔が出にくくなるため）。

5. 気に入らなければ Generate を押し直す（毎回別のseedで顔だけ描き直される）。1枚あたり約5分かかる
   - この設定なら、**マスク外で変化するのはマスク境界の約10px帯だけ**。服・ポーズ・影は完全に維持される
6. 4枚そろえる。**必須は `normal` と `suspicious` の2枚**、`smile` と `cold` は推奨。

## STEP 4. 透過・位置合わせ（スクリプト）

背景の切り抜きと、彼女とのサイズ合わせは `chara_cutout.py` が行う。追加インストールは不要（Pillowだけ）。

1. STEP2〜3の出力4枚を、作業用フォルダにこの名前でコピーする
   ```
   normal.png / suspicious.png / smile.png / cold.png
   ```

2. **腕と胴の間の白を先に洗い出す。** 画像の外周とつながっていない白は、自動では抜けない
   （白いインナーや腕時計の文字盤と区別がつかないため）。まず一覧を出す。
   ```
   python chara_cutout.py <作業用フォルダ>/normal.png --list-islands
   ```
   面積とbboxが並ぶので、**どれが背景でどれが服か**を画像と見比べて判断する。
   背景だったものの `--hole x,y` をメモする。典型的には次の3つが背景になる。
   - 左腕と胴の間の縦長の隙間（面積が数千と大きい）
   - 右腕と胴の間の隙間（腕時計やポケットで上下に分断され、2つに分かれることが多い）

   逆に**残すもの**：白いインナー、腕時計の文字盤、シャツのボタン、髪のハイライト、
   笑顔の歯（`smile` だけ島が1つ増える）。

3. 4枚まとめて透過にする（`--hole` は背景の数だけ並べる）
   ```
   python chara_cutout.py <作業用フォルダ>/*.png --hole 204,961 --hole 610,1002 --hole 615,1043 -o public/assets/chara/friend
   ```
   4枚は顔以外が同一なので、**穴の座標は4枚とも同じで通る**。

4. 出力ログで、4枚とも同じ数字になっていることを確認する
   ```
   頭頂y=35 人物高=1117 幅=... 中心x=416
   ```
   幅だけは表情差分でも数px動くことがある。**頭頂yと中心xがズレていたら、その1枚は作り直し**
   （inpaintで髪や輪郭まで塗ってしまったケース）。

   ログ末尾に「白い島が残っている」と出るが、それがインナーや時計なら正常。
   背景を消し忘れていたら `--hole` を足して実行し直す。

スクリプトがやっていること：

- 画像の**外周から繋がっている白**と、`--hole` で指定した白の島を透過にする
- 輪郭の1px を明るさに応じて半透明にして、ジャギーを消す
- 人物を **彼女の1.05倍**に拡大し、頭頂が上端から35px、中心xが416pxに来るように置き直す
  （30歳の男女なので、友人は彼女より少し背が高く見えるべき。倍率は `--scale` で変更可）
- 位置合わせが不要なら `--no-align` を付ける

> 1.05倍は「頭の位置を彼女とそろえたまま人物だけ大きくする」処理なので、頭も5%大きくなる。
> 並べてみて頭が大きく見えるようなら `--scale 1.0` で出し直す。

### 頭頂でそろえると背が低く見えることがある

`--scale` の基準は**頭頂**なので、髪が逆立っているキャラだと、その髪のぶんだけ顔が下がる。
友人は髪のボリュームが彼女より33px多く、頭頂をそろえると顔が33px低くなって「背が低い」印象になった。

顔の大きさ自体を比べるときは、髪型に左右されない**顔幅**で見ること（友人142px・彼女144pxでほぼ同じだった）。
顔幅が同じなら拡大縮小はせず、**顎の高さがそろう位置まで上へずらす**。下に空くぶんは裾の帯を
引き伸ばして埋める（縦方向の構造しかない帯なら、数十pxの引き伸ばしは見た目に出ない）。

同じ処理を彼女の元画像に掛けると、出荷済みの `girlfriend/normal.png` と
頭頂y・人物高・幅・中心x がすべて一致する。

## STEP 5. 配信用データに反映する

1. WebPを生成する
   ```
   python optimize_assets.py
   ```
2. `sw.js` を2箇所直す
   - `CACHE_VERSION` を `'kare-v5'` → `'kare-v6'` に上げる
   - `CRITICAL` 配列の girlfriend の行の上に、置いた枚数だけ追記する
     ```js
     './public/assets/chara/friend/normal.webp',
     './public/assets/chara/friend/suspicious.webp',
     ```
3. ブラウザで開いて確認する。`normal.png` 1枚だけの状態でも動く
   （未配置の差分は自動でプレースホルダ表示になる）

## チェックリスト

- [ ] Clip skip が **2** になっている（1のままだと彼女と色味・線が変わる）
- [ ] チェックポイントが `holyMixIllustriousxl_v1`、LoRAとVAEが未指定
- [ ] 4枚とも**同じnormalからinpaintで派生**させた（別々にtxt2imgしていない）
- [ ] 4枚の服・ポーズ・影が完全に一致している（並べてパラパラ切り替えて確認）
- [ ] 金髪になっている（黒髪・茶髪が出ていない）
- [ ] スーツ・ネクタイ・眼鏡が入っていない（土曜の昼の休日の場面）
- [ ] 背景のアルファが0（ゲーム画面で白い箱にならない）
- [ ] 768×1152 のPNG（RGBA）で `public/assets/chara/friend/` に入っている
